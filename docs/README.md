# 문서

기능 하나에 문서 하나다. 각 문서는 왜 그렇게 했는지, 어떻게 도는지, 무엇이 어느 파일에 있는지를
한 장에 담는다. 코드를 옮겨 적지 않는다 - 코드는 바뀌고 문서는 안 바뀐다.

## 로그인

| 문서 | 무엇 |
|---|---|
| [인가 코드 흐름](인가-코드-흐름.md) | 통합 로그인. 앱이 토큰을 받는 유일한 길. 로그인 화면은 auth 에 하나만 있다 |
| [비밀번호 로그인](비밀번호-로그인.md) | auth 로그인 화면의 비밀번호 폼. 잠금과 계정 열거 방지 |
| [이메일 인증번호](이메일-인증번호.md) | auth 화면에서 비밀번호 없이 6자리 숫자로 로그인하거나 가입하는 길 |
| [소셜 로그인](소셜-로그인.md) | 구글 계정으로 들어오는 길. auth 가 브로커로 받는다. 계정 자동 연결 |
| [가입 이메일 확인](가입-이메일-확인.md) | 가입할 때 이메일 주인인지 확인하는 두 걸음. 경우마다 무엇이 보이고 번호가 어떻게 되나 |
| [회원가입](회원가입.md) | auth 의 가입 화면과 `prompt=create`. realm 이 정하는 가입 정책 |
| [운영 화면 로그인](운영-화면-로그인.md) | auth 자신의 화면이 MASTER realm 의 앱으로 로그인한다. 토큰은 쿠키, 8080 전체를 지킨다 |
