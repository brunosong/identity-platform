직원 관리자 realm: employee

이메일 OTP 로 로그인한다. 직원은 비밀번호 계정을 갖지 않는다 — 직원 계정을 만드는 RegisterEmployeeAccountService 가 이메일 계정만 만들기 때문이다.

연결 대상

이 페이지와 출처가 다르다. auth-service 의 app.cors.allowed-origins 에 이 들어 있어야 한다.

로그인 — 이메일 OTP

admin@example.com 은 로컬 시드가 심어둔 부트스트랩 관리자다. 직원 계정은 관리자만 만들 수 있어(AUTHZ_MANAGE 필요) 최초 한 명은 데이터로 심는다.
local 프로파일은 메일을 보내지 않고 고정코드 123456 을 쓴다. 발송 API 는 가입 여부와 무관하게 늘 202 다 — 계정 열거를 막기 위해서다.

            고객 서랍에는 이 이메일이 없으므로 코드가 만들어지지 않고, 그 코드로는 로그인되지 않는다.
